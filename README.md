# Digital Emlak Hub

Аналитический терминал рядом с государственными аукционами Азербайджана (herrac.gov.az). Покупатель открывает реальный лот и видит, откуда взялась каждая цифра.

**Неизвестные данные не заменяются придуманными значениями.** Нет сбора в карточке — сбор не вычитается. Нет ремонта — прибыль не считается. Нет подтверждённого рынка и нет своей цены продажи — прибыль не считается.

## Стек

- Next.js 16 (App Router), React 19
- PostgreSQL и Prisma
- Сессия: email, bcrypt, httpOnly cookie `eh_session` (jose). Firebase в проекте нет.
- Рынок: публичные объявления Turbo.az и Bina.az, без AI

## Как запустить с чистой машины

```bash
cp .env.example .env
# впишите SESSION_SECRET, CRON_SECRET и SEED_ADMIN_PASSWORD
docker compose up -d
npm install
npx prisma migrate deploy
npm run db:seed
npm run dev
```

Откройте http://localhost:3000. Терминал: http://localhost:3000/dashboard.

Проверки:

```bash
npm test
npm run lint
npm run build
```

`npm test` считает деньги, Market Engine, изоляцию пользователей и реферальные начисления. Изоляционные тесты читают локальный `DATABASE_URL` и не ходят в Hərrac.

## ENV

Секреты только здесь. Пороги продукта — в `src/lib/productRules.js`, не в `.env`.

| Переменная | Зачем |
| --- | --- |
| `DATABASE_URL` | PostgreSQL. Без неё API отвечает «база не настроена» и не подставляет демо. |
| `SESSION_SECRET` | Подпись cookie. В production обязателен. |
| `CRON_SECRET` | Заголовок `x-cron-secret` для `POST /api/admin/herrac/sync`. |
| `SEED_ADMIN_EMAIL`, `SEED_ADMIN_PASSWORD` | Только `npm run db:seed`. Пароль обязателен, значения по умолчанию нет. |
| `NEXT_PUBLIC_ALLOW_DEMO` | `1` и только не в production: локальный демо-вход, если базы нет. В production игнорируется. |
| `NEXT_PUBLIC_M10_PHONE` | Номер для ручной оплаты, если задан. |

## PostgreSQL

База поднимается через `docker compose up -d` (Postgres 16, пользователь `emlak`, база `emlak_hub`).

```bash
npx prisma migrate deploy
npm run db:seed
```

CI (`.github/workflows/ci.yml`) на каждый push и pull request: `npm ci`, lint, test, build. Красный lint, тест или сборка останавливают merge.

Лоты, пользователи и платежи читаются из базы. Если база недоступна, экран показывает ошибку и кнопку повтора, а не бесконечную «Загрузка терминала…» и не чужие лоты.

## Hərrac sync

`npm run herrac:sync` или `POST /api/admin/herrac/sync` (админ или `CRON_SECRET`).

Клиент берёт публичный список и карточку. В лот попадают только поля карточки: старт, сбор, задаток, текст. Сбор и задаток, которых нет в карточке, остаются неизвестными.

Если Hərrac не ответил, в журнал пишется техническая ошибка, человеку — «Hərrac временно недоступен. Попробуйте позже.» Список `/os/v1/auctions` иногда отвечает 500 `AUCTION_ORGANIZATION_SERVICE_001`. Тогда новые лоты обнаружить нельзя, а уже известная карточка по ID может открываться. Расписание само не ставится.

## Turbo / Bina

`src/lib/markets/turbo.js` и `src/lib/markets/bina.js`.

Авто: та же марка и та же модель. Чужую модель той же марки не подмешиваем. Год лота неизвестен — рыночную цену не публикуем.

Недвижимость: тот же тип и тот же район. Соседи по городу показываются отдельно и в медиану не входят. Нет района или город не Баку — Баку не подставляем.

Сбой источника: `marketStatus: "unavailable"` и текст «Рыночные данные временно недоступны. Попробуйте позже.»

## Market Engine

`src/lib/markets/engine.js`. Пороги: `src/lib/productRules.js` (`MARKET_RULES`).

Проверяет год, пробег, двигатель, площадь, комнаты, район. Считает, сколько объявлений найдено, сколько подошло и почему остальные отброшены. Выброс цены — правило Тьюки (IQR × 1.5).

Достоверность — не оценка AI: `high`, `medium`, `low`, `insufficient`, `unavailable`. В калькулятор как рыночный ориентир уходят только `high` и `medium`.

Квартиры разных городов не считаются аналогами. Подключённый каталог bina.az покрывает Баку и отдельные посёлки Абшерона. Xırdalan, Sumqayıt, Yevlax и другие города без своего идентификатора в этом каталоге не оцениваются ценами Баку. Дом, квартира, коммерция и земля не смешиваются. Если подходящих объявлений нет, рыночная цена не назначается.

Если рынка нет, инвестор указывает свою предполагаемую цену продажи. Прибыль и максимальная ставка считаются по введённым данным. Пустой расход остаётся неизвестным и не превращается в ноль. Своя цена не повышает Emlak Score и не записывается как рыночная оценка. При подтверждённом рынке по-прежнему можно выбрать «По моей цене».

## Investment Engine

`src/lib/analysis/invest.js`. Пороги продажи и границы ставки: `INVEST_RULES` в `src/lib/productRules.js`.

Подтверждённый ориентир продажи — граница Market Engine: осторожный p25, рынок — медиана, оптимистичный p75. Инвестор может посчитать сделку по своей цене продажи и тогда, когда рынок уже подтверждён. Рыночный ориентир при этом не меняется. Своя цена не повышает Emlak Score и не записывается как рыночный факт.

Прибыль = ориентир − ставка − ремонт − прочие − сбор Hərrac − расходы на продажу.

ROI = прибыль / (ставка + ремонт + прочие + сбор + продажа).

Максимальная ставка при желаемой прибыли суммой: ориентир минус все эти расходы и минус сама прибыль. При желаемой прибыли процентом процент — это ROI на вложенный капитал, не доля от цены продажи.

Пустой ремонт — неизвестно, не ноль. Ноль, который ввёл человек, в формулу входит. Поле `repairCost` функция не читает. Задаток показывается и из прибыли не вычитается. Сбор вычитается только если он есть в карточке Hərrac.

## Data origins

Единственный список: `src/lib/origin.js`.

- `herrac_fact` — цифра из карточки Hərrac
- `market` — цифра Market Engine
- `assumption` — явное допущение, его можно выключить (сейчас это 3% на продажу)
- `user` — ввёл инвестор
- `unknown` — поля нет; в формулу как ноль не подставляется

Других имён (`herrac`, `fact`, `demo`) для денег нет.

## Структура проекта

```
src/app/api/lots/[id]/analysis   отчёт по одному лоту
src/lib/herrac                   клиент, синк, нормализация карточки
src/lib/markets                  Turbo, Bina, Market Engine
src/lib/analysis/invest.js       максимальная ставка, прибыль, ROI
src/lib/analysis/economics.js    сценарий сделки без выдуманных расходов
src/lib/analysis/visionLocal.js  неактивный слот Vision: текст карточки, без цены ремонта
src/lib/productRules.js          пороги продукта
src/lib/origin.js                происхождение сумм
prisma                           схема и миграции
tests/money.test.mjs             тесты на деньги
```

## Как проходит анализ одного лота

Hərrac → нормализация карточки → Market Engine → проверенные аналоги → диапазон рынка → ввод инвестора → Investment Engine → максимальная ставка / прибыль / ROI.

`GET /api/lots/[id]/analysis` собирает этот путь. В прибыль медиана попадает только если `usableForValuation` истинен.

## Оплата и Emlak Partners

Тарифы на сервере: 9,90 ₼ / 30 дней, 24,90 ₼ / 90 дней, 79,90 ₼ / 365 дней. Цена из браузера не принимается. Пока провайдер не подключён, заявка остаётся `pending`, а `POST /api/payments/webhook` отвечает 501 и PRO не включает.

Emlak Partners начисляет дни сервиса, не деньги: +7 пригласившему и +3 приглашённому после первой подтверждённой оплаты. Повторный webhook и повторная покупка бонус не удваивают.
